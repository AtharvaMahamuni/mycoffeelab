## 2. Explicit Assumptions Underpinning the Plan

1. **[Assumption 1: Mobile Dominance]:** We assume >70% of home brewing and menu discovery searches occur on mobile devices in kitchens or coffee shops. *Implication: Desktop 3D features must never compromise mobile 2D speed.*
2. **[Assumption 2: Grams as the Universal Specialty Currency]:** We assume that any user seeking to improve their coffee beyond instant powder is willing to use grams (mass) rather than tablespoons. *Implication: Grams are the primary UI unit, with ounces provided solely as a secondary toggle.*
3. **[Assumption 3: Organic Link Velocity via Free Utilities]:** We assume that coffee bloggers, Reddit users (r/Coffee), and forum members will link to an ad-free, beautiful calculator significantly more often than to ad-cluttered legacy tools like Omni Calculator.
